# Contributing

Open an issue to discuss a change before a pull request, unless it is a small fix.

A pull request:

- Brings tests for the functionality it adds or the bug it fixes, in the automated suite.
- Passes `make ci`, which CI runs on Linux and macOS.
- Follows [docs/GUIDELINES.md](docs/GUIDELINES.md).

[docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) covers setup and the project's rules.
